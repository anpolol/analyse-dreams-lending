# Блог AnalyseDreams — генератор постов

Посты пишутся в простом формате `.md` в папке `blog/posts/`, а HTML-страницы,
список карточек в `blog/index.html` и `sitemap.xml` собираются автоматически одним скриптом.

## Что нужно для работы

- Python 3 (уже есть на macOS)
- `sips` (встроен в macOS, нужен для автосжатия картинок)
- Локальный сервер для предпросмотра (см. ниже)

## Как добавить новый пост

1. **Положи картинку** (обложку) в `blog/img/`
   - Расширение: `.jpg` (для фото/иллюстраций) или `.png` (если нужна прозрачность)
   - Имя файла латиницей, без пробелов, например `bardo.jpg`
   - Размер/вес любой — скрипт сам сожмёт до 800px и ~150 КБ

2. **Создай файл `blog/posts/<имя-поста>.md`** со структурой:

   ```markdown
   ---
   title: Заголовок поста
   date: 2026-10-30
   category: Теория
   slug: moj-post
   cover: /blog/img/bardo.jpg
   preview: Короткое описание для карточки и SEO (1–2 предложения).
   ---

   ## Первый раздел

   Текст поста. Поддерживается лёгкая разметка:

   **жирный**, *курсив*, [ссылка](https://example.com)

   - пункт списка
   - ещё пункт

   > цитата из сна

   ## Второй раздел

   Картинка внутри текста (необязательно):

   ![Подпись к картинке](/blog/img/detail.jpg)
   ```

3. **Запусти сборку:**

   ```sh
   python3 build_posts.py
   ```

   Скрипт:
   - сожмёт картинки в `blog/img/` (если нужно)
   - сгенерирует `blog/<slug>.html` для каждого `.md`
   - перестроит список карточек в `blog/index.html` (новые сверху по дате)
   - обновит `sitemap.xml`

## Поля frontmatter

| Поле          | Обязательно | Описание                                         |
|---------------|-------------|---------------------------------------------------|
| `title`       | да          | Заголовок. `*слово*` → курсивный акцент в h1      |
| `date`        | да          | Дата в формате `ГГГГ-ММ-ДД`                      |
| `category`    | нет         | Категория (Теория / Практика / Заметка)           |
| `slug`        | нет         | URL-имя файла; если не указать — имя `.md` файла   |
| `cover`       | нет         | Путь к обложке; если не указать — заглушка         |
| `preview`     | да          | 1–2 предложения для карточки и meta description    |
| `reading_time`| нет         | Минут чтения (число)                              |
| `description` | нет         | Свой meta description (иначе берётся `preview`)   |

## Что скрипт делает автоматически

- Убирает промо-блок Telegram из начала поста (`@dreams_analyse_bot`,
  `analysedreams.com`, «Бесплатный анализ сна», «Построить карту»)
- Убирает ссылки на Telegram (`t.me/...`) из всего тела
- Убирает эмодзи из заголовков `## 📖 ...` → `## ...`
- Строит оглавление (TOC) из h2, если их 2 и больше
- Форматирует дату `2026-10-30` → «30 октября 2026»
- Добавляет микроразметку `BlogPosting`, хлебные крошки, canonical, og-теги

## Предпросмотр локально

Открывать `index.html` двойным кликом **нельзя** — абсолютные пути
(`/blog/...`, `/image_*.jpg`) не сработают через `file://`. Нужен локальный сервер.

Запусти в корне проекта:

```sh
python3 -m http.server 8000
```

Открой в браузере:
- Лендинг: http://localhost:8000/
- Блог: http://localhost:8000/blog/
- Пост: http://localhost:8000/blog/<slug>.html

Чтобы остановить сервер — `Ctrl+C` в терминале.

## Проверка после добавления поста

1. Открой http://localhost:8000/blog/ — твоя карточка должна быть первой сверху
2. Кликни на неё — откроется пост, проверь:
   - заголовок, дата, время чтения, категория
   - обложка сверху
   - оглавление (если 2+ раздела)
   - текст с разметкой (жирный, курсив, списки, цитаты)
   - кнопка «Анализ сна бесплатно →» после обложки
   - CTA-блок с луной в конце
3. Если что-то не так — поправь `.md` и перезапусти `python3 build_posts.py`,
   потом обнови страницу в браузере (`Cmd+R`)

## Шпаргалка по разметке

| Что             | Как писать                          |
|-----------------|-------------------------------------|
| Заголовок секции | `## Заголовок`                     |
| Подзаголовок     | `### Подзаголовок`                  |
| Абзац            | пустая строка между абзацами         |
| Жирный           | `**текст**`                         |
| Курсив           | `*текст*`                           |
| Список            | `- пункт` (маркер) или `1. пункт`  |
| Цитата            | `> текст цитаты`                    |
| Ссылка            | `[текст](https://url)`             |
| Картинка          | `![подпись](/blog/img/file.jpg)`    |

## Структура папок

```
blog/
├── posts/              ← исходники .md (пишешь тут)
├── img/                ← картинки постов (кладёшь тут)
├── index.html          ← список карточек (генерируется)
├── <slug>.html         ← готовые посты (генерируются)
├── blog.css            ← стили блога
├── placeholder.svg     ← заглушка обложки
└── post-template.html  ← справочный пример (не используется)
build_posts.py          ← генератор
sitemap.xml             ← генерируется
```
